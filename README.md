# Customer Management System

A full-stack web application designed to simplify customer data management. It allows authenticated users to manage customer records through a clean and responsive interface with secure data storage.

## 🚀 Features

* 🔐 User authentication with Clerk
* 👤 Add new customers
* 📋 View customer details
* ✏️ Update customer information
* 🗑️ Delete customer records
* 🏷️ Manage customer status
* 🔍 Search customers
* 📊 Customer statistics dashboard
* 🔄 RESTful API
* 📱 Responsive user interface
* ✅ Form validation

## 🏗️ Architecture

text
